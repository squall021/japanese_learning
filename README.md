# 日和日語

繁體中文的日文入門學習網站，原生 HTML/CSS/JavaScript，無框架與建置依賴。

## 網站與版本

- 線上網站：https://squall021.github.io/japanese_learning/
- 原始碼：https://github.com/squall021/japanese_learning
- 儲存點與回復方式：[RESTORE.md](RESTORE.md)
- 原 Sites 部署資訊保留在 `.openai/hosting.json`，目前發布目標為 GitHub Pages。

推送至 `main` 會由 GitHub Actions 自動檢查並發布 `dist/`。也可在 Actions 的 `Deploy Japanese Learning` 手動指定儲存點標籤，重新發布舊版。

搬移網址後，先在舊網站「我的學習」匯出進度，再於新網站匯入，才能帶入原本的本機學習紀錄。

## 啟動

在此目錄執行 `node server.mjs`，瀏覽 http://127.0.0.1:5180 。靜態網站內容位於 `dist/`，可直接部署。

執行檢查：`npm run check` 與 `npm test`。不需要安裝 npm 套件。

## 功能

- 平假名、片假名、濁音、半濁音、拗音，點擊發音與每行五題聽音測驗。
- 92 個基本假名手寫練習：逐筆動畫、暫停、慢速、描寫、自由書寫、復原、清空、筆跡重播、並排與疊合對照。
- 點選假名字卡後，可在「聽發音」旁直接進入該字手寫。五十音頁的「繼續上次手寫」分別記住平假名與片假名最後開啟的字（含寫字板內切換），重新載入或匯入進度後也能接續；初次使用從「あ／ア」開始。
- 描寫與自由書寫的完成次數分開保存並包含於進度匯出。關閉寫字板後清除本次筆跡，不將描寫當作熟練判定。
- 五個情境課程、對話、詞語卡、可點擊句型拆解、選擇／聽力／輸入練習。
- 助詞教學專區：六課（は、を、の、も、に／で、に／へ）、18 組情境例句與 24 題練習。可點選例句助詞查看本句關係、聆聽整句，並沿用振假名顯示設定。
- 助詞每個選項都有對應回饋；一般移動句接受「に」與「へ」兩種合理答案。固定題庫的混合練習每課隨機抽一題，共六題。
- 助詞變化練習：依句型與經確認的相容詞彙組題，共 299 種情境與句型組合（は 40、を 53、の 36、も 40、に／で 90、に／へ 40）。綜合練習每課出一題；單課加強出六題，平均涵蓋該課用法。提供生詞提示、完整答案與中文意思。
- 保存最近看過的 120 個變化題識別碼（包含於備份），優先未看過的題目，再取較早出現的題目。同一組六題不重複句子；題目數量有限，練習足夠多次會再次遇到舊句子。只記錄實際顯示的題目，未作答不計入答題或課程完成紀錄。
- 助詞複習依八種具體用法保存：答錯立即加入易錯清單，連續答對兩次移出；答對後依連續答對次數安排 1、3、7、14 天複習。每種待複習用法配一題基礎題與一題變化題，兩題句子不同。此為簡易排程，不代表精確的熟練度測量。
- 原有句型拆解中的相關助詞可連到助詞小課。助詞進度、最佳成績與複習資料納入匯出／匯入，與舊備份相容。練習中每題即時保存，離開後會重新開始一組題目。
- 基礎文法專區：名詞句、名詞否定句、名詞疑問句、動詞禮貌句、動詞過去、い／な形容詞、動詞分類、ます形、ない形，共九堂課，27 組可點擊拆句例句、54 道練習（21 題選答、15 題組句、14 題變換、4 題分步活用）。沿用振假名開關與整句合成語音。
- 組句以點選詞塊操作，支援移回、重新排列與鍵盤焦點接續；未使用全部詞塊前不能提交。每題第一次送出後保存分數與概念紀錄，重複點擊不重複計分；六題全部完成後才標記本課完成。
- 名詞與な形容詞的開放否定變換題接受「じゃありません／ではありません／じゃないです／ではないです」；い形容詞題接受「熱くないです／熱くありません」。動詞課比較「ます／ません／ました／ませんでした」。提供逐選項解析、完整答案及組句與變換題的中文意思。
- 動詞組句接受教材內合理的語序替換，例如「図書館で本を読みません」和「本を図書館で読みません」；助詞與名詞必須正確連接。組句句號跟隨最後詞塊換行。
- 第 7～9 課使用白話中文、三條路線圖、逐步字尾變化圖與原生 SVG 圖示。21 個已確認分類的動詞可切換「先看原形／看哪裡變／放回句子」，並附九種五段字尾對照表及例外提醒。常用單字先顯示，其餘可展開；圖解瀏覽不計入作答成績。
- 分步活用先選類別，再選形式；分類和形式分開追蹤易錯概念。兩步第一次都答對才計本題答對，分類答錯仍可接著練正確路線；變化答對時會明確指出。各步即時保存，重複點擊不重複計分。
- 文法綜合練習從九課各抽一題，共九題；易錯與到期複習依十八個概念抽題，使用 54 題教材。答錯立即加入複習，連續答對兩次移出，答對後安排 1、3、7、14 天間隔。文法進度納入備份並相容舊版資料。
- 全域振假名設定、收藏、瀏覽器本機進度、JSON 匯出與經確認後匯入。
- 簡易間隔複習：還不熟加入本次隊尾並保留近期到期；想了一下較短間隔；記得逐步延長間隔。
- Web Speech API 日文合成語音，支援聲音選擇、速度選擇、播放狀態與無日文聲音提示。

## 語音與資料

需要瀏覽器與作業系統提供日文合成語音。網站不以其他語言聲音冒充日語。可能需要先安裝作業系統日文語音；聲音是否由本機或網路合成取決於裝置供應商。沒有後端帳戶與跨裝置同步。進度保存在 `localStorage` 的 `hiyori-v1`；不同網站來源分開保存，清除瀏覽器資料前請匯出。

課程內容與拆解為靜態教材。手寫目前涵蓋 46 個基本平假名及 46 個基本片假名；濁音、半濁音、拗音與小寫假名暫不提供手寫範本。筆畫數提示不是字形正確度評分。尚未包含口型影片、AI 對話、錄音評分或任意文章自動分析。網站字型由 Google Fonts 載入，無法連線時使用系統後備字型。

## 助詞教材

繁體中文解說、例句安排及選項回饋由本站編寫；基本用法參照 [國際交流基金《いろどり》文法筆記](https://www.irodori.jpf.go.jp/assets/data/Grammar_all.pdf)，移動句「に／へ」的替換參照 [東京外國語大學 NへVます](https://www.coelang.tufs.ac.jp/mt/ja/gmod/contents/explanation/026.html)。未複製來源教材的整課內容或圖像。

教材位於 `dist/particles/data.js`；每題具有具體用法、情境、選項、可接受答案陣列及各錯誤選項的回饋。新增題目時須確認多解情況，保留合理替代答案。第一階段未涵蓋「は／が」完整比較或每個助詞的全部用法。

變化組題規則位於 `dist/particles/generator.js`。場所、動作與物品按相容群組組合；名詞修飾採明確配對；「来ます」的情境指定說話者在目的地。模板同時產生題幹、情境、答案、回饋、標音及詞彙提示。基本文法與內容均在網站內提供，不呼叫 AI 或其他出題服務。

變化題不覆寫四題基礎檢核的最佳成績與課程完成狀態。新增或調整模板需檢查所有可生成組合、合理替代答案、同組重複、近期歷史避重複與題池耗盡後的行為。穩定題目識別碼是備份資料的一部分；調整語意時應更新模板版本。

## 基礎文法教材

教材位於 `dist/grammar/data.js`，課程與中文解說由本站編寫，基本用法參照 [國際交流基金《いろどり》文法筆記](https://www.irodori.jpf.go.jp/assets/data/Grammar_all.pdf)、[東京外國語大學：動詞的三種類型](https://www.coelang.tufs.ac.jp/modules/ja/gmod/contents_m/explanation/039.html) 及 [國際交流基金：ない形](https://www.kyozai.jpf.go.jp/kyozai/material/BTS00065/ja/render.do)。前六課涵蓋名詞句、動詞禮貌句及過去、形容詞入門；第七至九課補上五段／一段／不規則動詞分類、辭書形到ます形及ない形。尚未包含て形、其他完整活用或任意文字分析。

動詞資料位於 `dist/grammar/verbs.js`，依已確認的分類提供變化，不根據「る」結尾自動猜測類別。涵蓋九種五段字尾、一段與する／来る，以及帰る、入る、走る、起きる、う→わ、ある→ない和来る讀音變化等提醒。`verb-guide.js` 產生圖解與本站繪製的 SVG 圖示；不依賴外部圖片服務。圖說和操作有文字標籤，可使用鍵盤，並尊重減少動態效果設定。

每題以具體概念追蹤複習，與助詞進度分開保存在 `grammar` 欄位；沒有新 API 或後端依賴。課程最佳分數保留每次六題檢核的最高成績，綜合與複習不覆寫本課分數。`verify-grammar.mjs` 檢查所有課程與作答流程；`verify-verbs.mjs` 以獨立列出的預期答案檢查 21 個動詞、189 個圖解狀態，以及分類／變化分開保存、重複提交與舊備份相容。
